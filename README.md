Sales Data Analysis & Power BI Dashboard

📌 Short Description

An end-to-end data analytics project focused on analyzing sales data, identifying business trends, and creating an interactive Power BI dashboard for data-driven insights.

🎯 Purpose of the Project

- Analyze sales and customer data to identify key business trends.
- Understand product performance and customer behavior.
- Create an interactive dashboard to support business decision-making.

🛠️ Technologies Used

- Excel – Data preparation and initial analysis
- Python & Pandas – Data cleaning, transformation and EDA
- SQL – Data querying and business analysis
- Power BI – Dashboard development and data visualization

📊 Data Source

The project uses a structured sales dataset containing 1,000+ records with information related to customers, products, sales, and other business attributes.

✨ Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based business analysis
- Interactive Power BI dashboard
- KPI tracking and data visualization
- Sales and product performance analysis

🔍 Key Highlights

- Analyzed 1,000+ sales records to identify meaningful business insights.
- Used Python, Pandas and SQL for data preparation and analysis.
- Developed an interactive Power BI dashboard with KPIs, slicers, filters and charts.
- Identified important sales trends and product performance patterns.
